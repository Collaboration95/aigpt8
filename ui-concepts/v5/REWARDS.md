# Reward system: draft plan (to finalise later)

Status: placeholder. Nothing is built yet. Every decision is open.

## Goal
Games are fun because they pay off. Rewards should:
1. Make people want to play: return visits, streaks.
2. Pay for the preference data that playing gives Coupang, and make that trade visible.
3. Lead to Ship it, not compete with it.

## Candidate pieces
| Piece | What it is | Ties into |
|---|---|---|
| Coins | Earned per game round. Bonus for a streak or for accuracy (e.g. a close Price guess) | Spent as ₩ off at Ship it |
| Daily streak | One game a day, with a visible flame counter | Retention |
| Taste profile level | "Learned" chips add up to a profile that levels up | Shows context compounding. Profile chips are editable and removable (customer control) |
| Unlocks | Hidden-gem drops and early access to a new product for higher levels | Long-tail discovery |
| Accuracy rewards | Price guess within 10% gives a bonus; a fast Rapid fire run gives a combo multiplier | Makes the games skill-based |
| Instant coupon | Win state → "₩1,000 off" chip applied to that game's picks Ship it | Conversion |

## Where it shows in the UI
- Game result card: coins earned, streak count, profile XP bar.
- Ship it button: "Ship it · ₩20,700 −₩1,000".
- Header: small coin/streak pill (only after the first game, never on the white home).

## Open questions
- Coins vs direct coupons vs Rocket WOW perks: which fits Coupang best?
- Cap per day? (Avoid farming.)
- Does skipping or ✕ also earn coins? Honest negative signals are valuable data.
- How much of this to show in the 7-minute demo? Probably one moment: result card → coupon on Ship it.
